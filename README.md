# Iris — โปรแกรมดูรูปภาพสำหรับ macOS (แนว ACDSee)

แอป macOS แท้ เขียนด้วย Swift + SwiftUI ใช้ ImageIO ของ Apple ในการอ่านภาพ จึงเปิดได้ทุกฟอร์แมตที่ macOS รองรับ
(JPEG, HEIC, PNG, TIFF, GIF เคลื่อนไหว, WebP, RAW จากกล้องแทบทุกยี่ห้อ ฯลฯ)

**ต้องการ:** macOS 14 Sonoma ขึ้นไป, Xcode 15 ขึ้นไป (หรือ Command Line Tools ที่มี Swift 5.9+)

---

## วิธีรัน

### แบบที่ 1: เปิดใน Xcode (เหมาะกับช่วงพัฒนา)
1. ดับเบิลคลิก `Package.swift` (หรือ `open Package.swift`)
2. เลือก scheme **Iris** และปลายทาง **My Mac**
3. กด ⌘R

### แบบที่ 2: สร้างเป็นแอป `.app` ติดตั้งใช้งานจริง
```bash
cd Iris
chmod +x build-app.sh
./build-app.sh
cp -R build/Iris.app /Applications/
```
ครั้งแรกที่เปิด ถ้า macOS เตือนว่าไม่รู้จักผู้พัฒนา ให้คลิกขวาที่แอปแล้วเลือก **Open**
(แอปเซ็นแบบ ad-hoc สำหรับใช้เองในเครื่อง)

เมื่อเปิดโฟลเดอร์ Desktop, Documents หรือ Downloads ครั้งแรก macOS จะถามสิทธิ์ ให้กด **Allow**

## ฟีเจอร์ Phase 1

**โหมดเรียกดู (Manage)**
- แถบโฟลเดอร์ด้านซ้ายแบบแผนผัง: รายการโปรด / ตำแหน่ง / ไดรฟ์ (คลิกขวา → เพิ่มในรายการโปรด)
- ตารางภาพย่อ ปรับขนาดได้ด้วยแถบเลื่อนด้านล่าง หรือ ⌘+ / ⌘−
- ภาพย่อสร้างแบบขนานในพื้นหลังและมีแคช เลื่อนเร็ว ๆ ก็ไม่ค้าง
- ป้ายชนิดไฟล์ (RAW สีส้ม, HEIC, PNG, GIF ฯลฯ)
- แถบพาธ (breadcrumb) คลิกไปโฟลเดอร์แม่ได้, ปุ่มย้อนกลับ/ไปข้างหน้า/ขึ้นระดับบน
- ค้นหาชื่อไฟล์, เรียงตามชื่อ / วันที่แก้ไข / วันที่สร้าง / ขนาด / ชนิด
- เลือกหลายรูป: ⌘-คลิก, ⇧-คลิก, ⇧+ลูกศร, ⌘A
- ลากรูปออกไปวางในแอปอื่นหรือ Finder ได้ / ลากโฟลเดอร์เข้ามาเพื่อเปิด
- คลิกขวา: เปิดดู, เปิดด้วยแอปเริ่มต้น, แสดงใน Finder, คัดลอกพาธ, ย้ายไปถังขยะ

**แผงข้อมูลภาพ (Inspector)**
- พรีวิว + ฮิสโตแกรม RGB
- ข้อมูลไฟล์, ขนาดภาพ (MP), วันที่
- EXIF: กล้อง, เลนส์, ทางยาวโฟกัส, รูรับแสง, ชัตเตอร์, ISO, ชดเชยแสง, แฟลช, วันที่ถ่าย
- โปรไฟล์สี, ความลึกสี, DPI
- พิกัด GPS + ปุ่มเปิดใน Apple Maps

**โหมดดูภาพ (View)**
- โหลดภาพย่อขึ้นก่อนทันที แล้วตามด้วยภาพเต็มความละเอียด
- ถอดรหัสภาพถัดไปและก่อนหน้าไว้ล่วงหน้า กดถัดไปแล้วภาพขึ้นทันที
- ซูม: พอดีหน้าต่าง / 100% (พิกเซลจริงบนจอ Retina) / pinch บน trackpad / ดับเบิลคลิกตรงจุดที่ต้องการ
- ลากเพื่อเลื่อนภาพเมื่อซูมเข้า
- หมุนล้อเมาส์เพื่อเปลี่ยนภาพ (แบบ ACDSee) ขณะภาพพอดีจอ
- แถบภาพย่อด้านล่าง (filmstrip), แผงข้อมูลด้านขวา, สไลด์โชว์
- ปุ่มลูกศรซ้าย/ขวาบนภาพ (โผล่เมื่อเลื่อนเมาส์ไปที่ขอบ)
- GIF เคลื่อนไหวได้

## ฟีเจอร์ Phase 2

**คะแนนดาวและป้ายสี**
- กด **1–5** ให้ดาว, **0** ล้างดาว, **6 แดง / 7 เหลือง / 8 เขียว / 9 น้ำเงิน** (กดสีเดิมซ้ำเพื่อเอาออก) ใช้ได้ทั้งหน้ารวมภาพและโหมดดูภาพ ทำกับหลายรูปที่เลือกพร้อมกันได้
- แสดงดาวบนภาพย่อ, แถบสีใต้ภาพ, จุดสีหน้าชื่อไฟล์ และกดแก้ได้ในแผงข้อมูลภาพ
- ปุ่ม **กรอง** บนแถบเครื่องมือ: เลือกดูเฉพาะ ★3 ขึ้นไป หรือเฉพาะป้ายสีที่ต้องการ และเรียงตามคะแนนดาวได้
- ที่เก็บข้อมูล: ป้ายสีเป็น **Finder tag** (เห็นสีใน Finder และค้นด้วย Spotlight ได้), คะแนนดาวเก็บใน extended attribute ของไฟล์ — **ไม่แตะเนื้อไฟล์ภาพเลย**

**หมุนภาพแบบไม่เสียคุณภาพ** — กด **R** (ขวา) / **L** (ซ้าย)
- เปลี่ยนแค่ค่า EXIF Orientation ไม่บีบอัดภาพใหม่ ใช้ได้กับ JPEG, HEIC, PNG, TIFF
- ไฟล์ RAW หมุนไม่ได้ (จะมีข้อความแจ้ง) — คะแนนและป้ายสีถูกเก็บไว้ครบหลังหมุน

**เปลี่ยนชื่อหลายไฟล์** — กด **F2**
- รูปแบบชื่อใช้ตัวแทน `{n}` ลำดับ, `{name}` ชื่อเดิม, `{folder}` ชื่อโฟลเดอร์, `{date}` วันที่ถ่าย, `{time}` เวลาถ่าย
  เช่น `{date}_{folder}_{n}` → `20261117_ทริปเชียงใหม่_001.jpg`
- ตั้งเลขเริ่มต้น จำนวนหลัก ตัวพิมพ์ของนามสกุลได้ มีตารางตัวอย่างก่อนกดยืนยัน และเตือนชื่อชนกัน
- เปลี่ยนชื่อแบบ 2 จังหวะ ถ้าพลาดกลางทางจะคืนชื่อเดิมให้

**แปลง/ย่อขนาดภาพ** — **⇧⌘E**
- เป็น JPEG / HEIC / PNG / TIFF ปรับคุณภาพ และย่อด้านยาวสุด (1280 / 1920 / 2560 / 4K / กำหนดเอง)
- เลือกได้ว่าจะเก็บ EXIF หรือไม่ และลบพิกัด GPS ก่อนโพสต์ออนไลน์
- บันทึกไปที่โฟลเดอร์ `Export` ข้างไฟล์ต้นฉบับ (หรือเลือกเอง) ไม่ทับไฟล์เดิม มีแถบความคืบหน้าและปุ่มแสดงใน Finder

**ปรับปรุงจาก Phase 1**
- คีย์ลัดทุกตัวใช้ตำแหน่งปุ่ม จึงทำงานได้แม้เปิดแป้นพิมพ์ภาษาไทยอยู่
- คีย์ลัดไม่ทำงานซ้อนตอนเปิดหน้าต่างย่อยหรือหน้าต่างเลือกโฟลเดอร์

## ฟีเจอร์ Phase 3

**เทียบภาพ 2–4 ภาพ** — เลือก 2–4 รูปแล้วกด **C**
- ซูมและเลื่อนทุกภาพพร้อมกัน (ปิดได้ด้วยปุ่มรูปโซ่) เห็นส่วนเดียวกันของภาพแม้ความละเอียดต่างกัน
- คลิกเพื่อเลือกภาพ (กรอบสีฟ้า) แล้วกด 1–5 ให้ดาว / 6–9 ป้ายสี / ⌘⌫ ทิ้ง — เหมาะกับคัดภาพถ่ายต่อเนื่อง
- ← → หรือ Tab สลับภาพที่เลือก, Z หรือดับเบิลคลิกเพื่อสลับ พอดีหน้าต่าง ↔ 100%

**แสดงรูปใหม่อัตโนมัติ** — เมื่อมีไฟล์เพิ่ม/ลบ/เปลี่ยนชื่อในโฟลเดอร์ (เช่น ถ่ายแบบต่อสายกับคอมพิวเตอร์ หรือดาวน์โหลดรูปลงมา) รายการจะอัปเดตเองภายในไม่ถึง 1 วินาที

**รวมคู่ RAW+JPEG** — ไฟล์ชื่อเดียวกัน เช่น `IMG_0001.CR3` + `IMG_0001.JPG` แสดงเป็นรายการเดียว (ป้าย `JPG+CR3`)
- ดาว ป้ายสี ทิ้ง คัดลอก ย้าย และเปลี่ยนชื่อ ทำกับทั้งคู่พร้อมกัน
- แปลงไฟล์/หมุนภาพใช้กับ JPEG ตัวหลัก

**คัดลอก/ย้ายไปโฟลเดอร์** — เมนูเครื่องมือหรือคลิกขวา จำโฟลเดอร์ที่ใช้ล่าสุดไว้ 8 รายการ (⇧⌘C คัดลอก, ⇧⌘M ย้าย) ชื่อซ้ำจะต่อท้าย -2, -3 ให้ ไม่ทับไฟล์เดิม

**แก้ไขในแอปอื่น** — กด **E** เพื่อเปิดรูปใน Lumen, Photoshop หรือแอปที่ตั้งไว้ (ครั้งแรกจะให้เลือกแอป)

**หน้าตั้งค่า (⌘,)**
- ทั่วไป: แสดงรูปใหม่อัตโนมัติ, รวม RAW+JPEG, ถามก่อนทิ้ง
- การดูภาพ: สีพื้นหลัง (เทาเข้ม / ดำ / เทา 18% / ขาว), ขยายภาพเล็กเต็มจอ, ล้อเมาส์ = เปลี่ยนภาพหรือซูม, เวลาสไลด์โชว์
- เครื่องมือ: แอปแก้ไขภาพ, จัดการโฟลเดอร์ปลายทางล่าสุด

## ฟีเจอร์ Phase 4

**ใช้ร่วมกับ Lightroom (XMP)**
- อ่านดาวและป้ายสีที่ Lightroom, Bridge, Capture One หรือกล้องบันทึกไว้ (ทั้งไฟล์ `.xmp` ข้างไฟล์ และ XMP ที่ฝังในภาพ) อ่านในพื้นหลังหลังเปิดโฟลเดอร์
- เมื่อให้ดาว/ป้ายใน Iris จะเขียน `.xmp` sidecar ให้ไฟล์ RAW อัตโนมัติ (ปิดได้ในหน้าตั้งค่า) — ใน Lightroom สั่ง *Metadata → Read Metadata from Files*
- ไฟล์ `.xmp` ติดตามไปด้วยเวลาเปลี่ยนชื่อ ย้าย คัดลอก หรือทิ้ง
- ค่าที่ให้ใน Iris เป็นตัวหลัก (ล้างดาวแล้วจะไม่กลับไปอ่านค่าเก่าจาก XMP)

**ค้นหาขั้นสูง (⌥⌘F)** — ค้นในโฟลเดอร์ที่เปิดอยู่ รวมโฟลเดอร์ย่อยทั้งหมด
- ตามชื่อไฟล์, กล้อง, เลนส์, ช่วงวันที่ถ่าย, ช่วง ISO, ดาว, ป้ายสี, ชนิดไฟล์
- ผลการค้นหาใช้ได้ทุกคำสั่ง (ดูภาพ เทียบภาพ ให้ดาว แปลงไฟล์ ย้าย contact sheet) — กดหยุดได้ระหว่างค้นหา

**นำเข้าจากการ์ดกล้อง (⇧⌘I)**
- ตรวจหาการ์ดอัตโนมัติ (อ่านเฉพาะโฟลเดอร์ DCIM) หรือเลือกโฟลเดอร์ต้นทางเอง
- แยกโฟลเดอร์ตามวันที่ถ่ายจาก EXIF: `2026/2026-11-17`, `2026-11-17`, `2026/11/17`, `2026/2026-11` และเติมชื่อกิจกรรมได้ เช่น `2026-11-17 งานรับปริญญา`
- เลือก/ไม่เลือกเป็นรายวัน, ข้ามไฟล์ที่เคยนำเข้าแล้ว, รวมวิดีโอได้, ดีดการ์ดออกเมื่อเสร็จ
- ไม่ลบไฟล์บนการ์ด

**Contact Sheet (⌘P)** — สร้าง PDF รวมภาพย่อ (รูปที่เลือก หรือทั้งโฟลเดอร์)
- A4/Letter แนวตั้ง/แนวนอน, 2–8 คอลัมน์, แสดงชื่อไฟล์และค่าการถ่าย, พื้นหลังสีเข้มได้
- มีหัวเรื่อง จำนวนภาพ วันที่ และเลขหน้า เหมาะส่งให้ลูกค้าเลือกภาพหรือพิมพ์เก็บ
